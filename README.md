# IN1010 – Objektorientert programmering

Dette repositoriet inneholder mitt arbeid i **IN1010 – Objektorientert programmering** ved Universitetet i Oslo.

## Innhold
Repositoriet er strukturert etter undervisningsuker og obligatoriske oppgaver.


## Om emnet
IN1010 bygger videre på IN1000 og fokuserer på objektorientert programmering i **Java**, med særlig vekt på:
- Klasser og objekter
- Arv og polymorfisme
- Abstrakte klasser og grensesnitt
- Innkapsling
- God programstruktur og kodekvalitet

## Verktøy
- Java (JDK 17 eller nyere)
- Git / GitHub

## Merknad
Koden i dette repositoriet er kun ment som dokumentasjon av egen læring og øving, og skal ikke brukes til plagiering eller gjenbruk i obligatoriske innleveringer.

## Status
Oppdateres fortløpende gjennom semesteret.
